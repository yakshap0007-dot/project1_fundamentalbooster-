project name: fundamental booster

short discription our project:

-> This program collects some basic details from the user and performs small operations on the entered data.
The main goal of this project is to practice Python fundamentals in a simple and practical way.

--> The program demonstrates how Python handles:

1.User input
2.Different data types
3.Variable storage
4.Type conversion
5.Arithmetic calculations
6.Output formatting

--> FUNCTIONALITIES INCLUDED:-- 

User Detail Collection:-
The program asks the user to enter:
1.Name
2.Age
3.Height
4.Favourite Number

Birth Year Calculation:-
Using the entered age and current running year, the program calculates the approximate birth year.

Datatype Identification:-
The datatype of every stored value is displayed using Python's type() function.

Memory Address Display:-
The memory location of variables is shown using the id() function to understand how Python stores objects internally.


--> PROGRAM WORK FLOW:--

      ↓

      ↓

      ↓
End Program
